# One Native SwiftUI App for iPhone, iPad and Mac

Status: Accepted · 2026-11-19

The app is a single multiplatform SwiftUI target with iOS and native macOS destinations, not Mac Catalyst, built from a project file that XcodeGen generates from `ios/project.yml`. Data access, the comparison calculator and number formatting live in a local Swift package, `FootnoteKit`, which has no UI and no third-party dependencies and is tested with `swift test` on macOS, so most tests need no simulator. iPhone uses a tab bar (기업 · 소식 · 용어) with stacked navigation; iPad and Mac use `NavigationSplitView` with the company list in the sidebar, the company's filings in the content column and the filing or figure in the detail column. A filing's source opens in the system browser (`openURL`; on iPhone and iPad an in-app Safari view): the bundle already holds the figures, summary and filing details, so the app is fully usable offline and only the original document needs a network. Native macOS was chosen over Catalyst because Catalyst keeps iPad controls and spacing on the Mac, while a native destination gets Mac sidebars, toolbars, menus and window sizing from the same SwiftUI code. XcodeGen was chosen over a hand-edited project file because the project's targets and settings are then reviewable as YAML. The owner delegated this choice (2026-11-19).
